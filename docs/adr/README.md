# Registro de decisiones de arquitectura (ADR)

Cada archivo registra una decisión que afecta a todo el proyecto: el contexto en que se
tomó, qué se eligió, en qué estado está y qué consecuencias tiene. Un ADR aceptado no
se edita: si la decisión cambia, se escribe uno nuevo y el anterior pasa a «Superado
por ADR N».
